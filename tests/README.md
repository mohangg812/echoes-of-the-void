# Тесты

Все проверки запускаются headless-режимом Godot, внешние плагины не нужны.

## Юнит- и интеграционные тесты симуляции

```
godot --headless --path . --script res://tests/unit_tests.gd
```

Код возврата `0` — все проверки прошли, `1` — есть падения. В конце выводится
количество проверок и ошибок.

`unit_tests.gd` покрывает:

- сетку: тайлы, проходимость, двери, блокировку зрения/лучей/звука, A*;
- конусы зрения, защиту от диагонального «подглядывания», лучи турелей и лазеров;
- распространение звука и правила слуха обычной/элитной охраны;
- `AlarmManager` (тревога, кулдаун, снимки состояния) и историю отката;
- действия игрока: шаг, ожидание, рывок, вентиляция, шкафы, оглушение, взлом,
  двери, дым, манок, ЭМИ, плащ, лут и карманную кражу;
- ИИ охраны, камеры, турели, лазеры, победу/поражение, рейтинг и стиль;
- снимки состояния, `undo` и `compute_preview` без побочных эффектов;
- загрузку всех 7 кампаний и инварианты их данных;
- проигрывание строгих решений уровней 1–6.

## Существующие проверки

```
godot --headless --path . --script res://tests/smoke.gd
godot --headless --path . --script res://tests/replay.gd
godot --headless --path . --script res://tests/solver.gd -- 1 strict
godot --headless --path . --script res://tests/debug.gd -- 1 "R R U W"
```

`smoke.gd` проверяет загрузку уровней, `replay.gd` — сохранённые решения,
`solver.gd` ищет прохождение, `debug.gd` печатает карту по шагам.

> Примечание: сохранённое решение уровня 7 в `tests/solutions/level_7.txt`
> устарело относительно текущих правил ИИ. `replay.gd` сообщает об этом
> отдельно; юнит-тесты намеренно проверяют стабильные решения уровней 1–6.
