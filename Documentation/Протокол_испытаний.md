# Протокол испытаний

Игра «Теневой вор: Побег по пикселям», редакция требований 2.0. Дата: 27.11.2026. Среда: Windows 11 x64, сборка ОС 26100; Intel Iris Xe Graphics, Vulkan / Forward+; Godot 4.7.2. Для сохранений использованы изолированные профили.

## Фактические результаты

| Проверка | Результат |
|---|---|
| Импорт, unit/integration | Импорт выполнен. `unit_tests.gd`: 758 проверок, 0 провалов. |
| Проверка сцены | `session_tests.gd`: 10 проверок, 0 провалов. Проверены исполняемая сцена, маршрутизация звука, включение и остановка сирены, открытие настроек и отказ загрузки неверной миссии. При завершении headless-прогона движок предупреждает о неосвобождённых объектах воспроизведения WAV; в графическом прогоне самостоятельной сборки предупреждения не было. |
| Данные уровней | `smoke.gd`: все 7 карт загрузились, на каждой приняты 6 ходов. Юнит-тесты отклоняют отсутствующий/битый JSON, неверные поля, координаты и недостижимое ядро. |
| Сохранённые решения | `replay.gd`: 7 побед, ноль тревог в каждой, ранг A. Число ходов: 43, 56, 49, 82, 91, 62, 86. |
| Профиль и откат | Проверены отклонение неверных типов и рангов, повторная запись контрольного файла, точное восстановление снимка и история отката, отклонение изменившейся карты и неверного действия. UI подтверждения нового профиля не проверялся во всех вариантах повреждения. |
| Windows x64 | `export/EchoesOfTheVoid.exe` запущен из отдельной папки без исходников и без запуска редактора. В сборке создано обычное сохранение после 8 ходов. Отдельно игровой движок сборки воспроизвёл подготовленный журнал первых 42 ходов; последний ход выполнен клавишей в окне игры. Получена победа за 43 хода, ранг A, открыт уровень 2. |
| Интерфейс | Подготовлены восемь снимков основных экранов в 1600×900, в том числе настройки. Проверка всех экранов в физических 1920×1080 и на других масштабах не завершена. |
| Производительность и совместимость | Не измерялись 60 FPS и отклик на минимальном ПК; Windows 10 и иные GPU отдельно не проверялись. GitHub Actions настроен, но результат удалённого прогона и настройки PR не подтверждены. |
