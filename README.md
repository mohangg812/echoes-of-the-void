# Echoes of the Void — «Теневой вор: Побег по пикселям» (Shadow Thief: Pixel Escape)

Полный расширенный каталог из **48 ассетов (2D пиксель-арт)** для проекта на **Godot 4**.

## 📁 Структура каталогов

* `assets/sprites/` — Исходные спрайты высокого разрешения (`1024×1024 px` / HD).
* `assets/sprites_48px/` — Спрайты, подогнанные под базовую сетку игры (`48×48 px` и пропорционально для UI/масок) с фильтром `Nearest Neighbor`.

## ⚙️ Настройка в Godot 4

1. **Фильтрация текстур:**
   * В `Project Settings -> Rendering -> Textures -> Canvas Textures` установите **Default Texture Filter** в значение **`Nearest`**.
2. **Ориентация спрайтов:**
   * Все направленные спрайты (Игрок, Охранники, Камеры, Турели, Пули) ориентированы строго вправо (East / $0^\circ$), что соответствует `Vector2.RIGHT` и методу `look_at()`.
